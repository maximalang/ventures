## ЧАСТЬ A. Реально сильный аватар

### A1. Что значит «сильный» — критерии качества (сформировать измеримый рубрикатор)
Определить оси качества и как их мерить: реализм липсинка (RU!), мимика/эмоции, естественность головы/тела/жестов, консистентность персоны между роликами, качество голоса (интонации, паузы, ударения в RU), отсутствие «uncanny valley», освещение/фон/цветокор, стабильность кадров (без артефактов/мерцания), длительность без деградации. Итог: **рубрикатор 1–5 по каждой оси** — его потом возьмёт qa-гейт.

### A2. Стек для достижения качества (по осям)
Проверить по каждой оси, какой инструмент/техника её закрывает. Минимум охватить:
1. **Персона/внешность**: генерация консистентного лица (Flux/SDXL + LoRA персонажа vs готовые avatar-библиотеки HeyGen), права на сгенерированное лицо, как зафиксировать идентичность между роликами (seed/reference/IP-Adapter), legal-рамка (синтетическое лицо не реального человека).
2. **Липсинк и мимика RU**: MuseTalk, Hallo/Hallo2/3, EchoMimic v2/v3, Sonic, SadTalker, LatentSync, LivePortrait (drive-видео), Wav2Lip-наследники — качество именно на русском языке (известная проблема: многие модели хуже на RU), с источниками/бенчмарками/отзывами 2025–26.
3. **Голос RU**: Silero v5, Yandex SpeechKit, ElevenLabs (геоблок — обход?), Fish Audio, GPT-SoVITS, Kokoro, Cartesia — качество RU-интонаций, клонирование, цена, лицензия (коммерция!). Что даёт «живую» речь а не TTS-монотон.
4. **Тело/жесты/подача**: есть ли решения (HeyGen Avatar IV, Argil, Synthesia Expressive, Hedra Character-3) с жестикуляцией; альтернатива — «полукадр» (плечи+голова) как способ скрыть слабость; B-roll перекрытие.
5. **Сцена/свет/фон**: студийный вид без студии (нейро-фоны, lighting-согласование), цветокор под площадку.
6. **Постобработка**: апскейл (REAL Video Enhancer — у нас уже есть, 2.3k★), frame interpolation, denoise, удаление артефактов (VSR 12.9k★), sharpening — что реально улучшает восприятие.
7. **Сценарий/режиссура**: сильный аватар = не только картинка. Как писать текст под аватара (разговорный, короткие фразы, паузы), режиссура кадра, ритм.

### A3. Экономика качества: 3 уровня продакшена
Сравнить: (1) **Бюджетный** 0₽ локальный CPU — что реально достижимо, на каких осях провал; (2) **Средний** ~1300–2700₽/мес (D-ID/Vidnoz официально); (3) **Про** ~3800–4800₽/мес (FunPay-набор Kling/HeyGen/Gemini-VEO по данным E) и (4) **Максимум** — что даст лучший результат и сколько стоит (HeyGen Enterprise, Argil, аренда GPU Timeweb — у нас GPU по заявке в продажи; посчитать ₽/ролик). Для каждого: ₽ за 30-сек ролик, время генерации, качество по рубрикатору A1.

### A4. Верификация
Предложить конкретный протокол проверки: сделать 3 тестовых ролика на разных уровнях стека, оценить по рубрикатору, слепое сравнение (можно дать владельцу выбрать без подсказки какой дороже). Это станет входом для решения «какой уровень берём в прод».

## ЧАСТЬ B. Продажа аватар-видео как услуги (через freelance-отдел)

### B1. Рынок: кто покупает аватар-видео и за сколько (2025–26, с источниками)
1. **Биржи РФ**: Kwork, FL.ru, Workzilla, Хабр Фриланс, YouDo — есть ли категория «видео с ИИ-ведущим»/«аватар-ролик», какие ставки, сколько заказов в месяц (оценить спрос по количеству gigs/отзывов).
2. **Международные**: Fiverr, Upwork — ставки на AI-avatar/UGC-видео, доступность для РФ-исполнителя (нужен ли посредник, как выводят), конкуренция.
3. **Прямые каналы**: Telegram-чаты/каналы предпринимателей, экспертные сообщества (аватар для курсов/вебинаров), e-commerce (товарные ролики с аватаром), инфобизнес (прогревы), локальный бизнес (услуги), HR/обучение (внутренние видео компаний), медиа/новости (синтетические ведущие — есть ли RU-спрос).
4. **Продуктовые пакеты**: что именно продавать — (а) один ролик, (б) пакет 5–10 роликов, (в) «аватар под ключ» (персонаж+голос+бренд-кит) с передачей прав, (г) ежемесячная подписка на N роликов (ретейнер), (д) дубляж/локализация существующих видео на другие языки тем же аватаром, (е) аватар для вебинаров/курсов эксперта (клон его лица/голоса — с его согласия), (ж) «оживление» фото для мемориал-сегмента (этично? — оценить отдельно).
5. **Ценообразование**: рыночные ставки по каждому пакету (RU/междунар.), себестоимость наша (₽/ролик из A3), маржа, минимальный порог входа (наш freelance-финанс-гейт уже зафиксировал полы SKU 4000/6000₽ — проверить, применимо ли к аватар-SKU или нужен другой пол).

### B2. Конкурентный анализ
Кто уже продаёт такое в RU (агентства, фрилансеры, сервисы-конструкторы типа «видео с нейроведущим»): их цены, что входит, слабые места (где мы можем быть лучше/дешевле/быстрее). Найти 5–10 конкретных предложений со ссылками и ценами.

### B3. Юр-рамка продажи аватар-видео
1. Права на сгенерированный контент: что передаём заказчику, нужна ли отдельная лицензия, как оформлять (договор-оферта самозанятого).
2. Клон лица/голоса реального человека (заказчик хочет себя): требования согласия, риски (152-ФЗ персональные данные, biometrics), как оформлять согласие — найти практику/шаблоны.
3. Маркировка ИИ-контента: нужно ли маркировать ролики, сделанные на заказ, и кто отвечает (исполнитель/заказчик/площадка).
4. НПД-ограничения: самозанятый не может перепродавать чужой труд и не может работать с бывшим работодателем 2 года — проверить, что продажа аватар-видео собственного производства под НПД допустима (услуги собственного производства = ОК).

### B4. Готовый SKU и воронка продаж
1. Сформулировать 2–3 конкретных SKU (название, состав, срок, цена) — по образцу freelance-отдела (там уже есть работа по SKU, t_80a85496 — прочитать и согласовать).
2. Воронка: где ищем клиентов (конкретные площадки/чаты/холодные каналы в рамках политики — mass outreach запрещён, только отклики на открытые заказы + inbound-витрина), как показываем портфолио (демо-ролики нашего аватара — где хостим), как закрываем сделку, как сдаём.
3. Портфолио-план: какие 3–5 демо-роликов сделать первыми, чтобы продавать (тематики, длительность, где публикуем).
4. Интеграция с нашим конвейером: как фриланс-заказ проходит через video-отдел (карта на board video от board freelance — по ORG_MODEL.md отдел обслуживает все продукты).

### B5. Экономика направления
Расчёт: при N заказах/мес × средний чек − себестоимость − налоги = чистая прибыль/мес. Сценарии: пессимистичный/реалистичный/оптимистичный. Точка безубыточности (сколько роликов/мес нужно, чтобы окупить прод-стек A3). Сравнение с клиппингом (Стек 1) по ₽/час.
