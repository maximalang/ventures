## 0. Юридическая/этическая рамка (обязательный первый раздел)

1. **Персонаж — полностью синтетический, сгенерированный с нуля.** Никаких реальных лиц (владельца, знаменитостей, стоковых моделей), никакого клонирования чужих голосов. Это виртуальный блогер — легальная практика с прецедентами (раздел 2).
2. **Маркировка AI обязательна на каждой площадке.** Требования зафиксированы в разделе 4 (YouTube, TikTok, Meta). Скрытие синтетики = принудительный лейбл/демонетизация/удаление канала.
3. **Голос** — синтетический TTS; клон голоса владельца — только с его письменного согласия (отдельный touchpoint, вне этой карты).
4. **Честность перед брендами:** кампании Klipni типа «живой человек» = NO-GO фактом (раздел 4.1). Обход требований брифа не предлагается.
5. **Лицензионная ловушка OSS (важно):** популярные face-модели InsightFace (antelopev2/buffalo_l) — non-commercial. Они входят в SadTalker, LivePortrait, InstantID, PuLID → коммерческое использование требует замены детектора лиц или override владельца. Источники: LivePortrait LICENSE/issue #548 (github.com/KwaiVGI/LivePortrait/blob/main/LICENSE; github.com/KwaiVGI/LivePortrait/issues/548), InstantID README (github.com/InstantID/InstantID), PuLID issue #18 (github.com/ToTheBeginning/PuLID/issues/18). Confidence: HIGH.
6. **Пробел:** статус закона РФ о маркировке ИИ-контента на 09.2026 — не проверен в рамках карты (`null`, проверить перед прод-запуском; для зарубежных площадок действуют их правила из раздела 4).

### 1d. Рекомендуемый стек (2 варианта)

**Вариант 1 — «бесплатный пилот» (старт завтра):**
- Сценарий: video-director → TTS: Silero v5_cis_base MIT локально (0₽) или Edge TTS → аватар: **Vidnoz free (3 мин/день, вотермарка 720p)** либо HeyGen free (3 ролика/мес) → монтаж: MoneyPrinterTurbo (MIT) + autoclip.
- 30-сек клип: ~0₽, потолок ~6 клипов/день (лимиты free). Вотермарка = риск приёмки в кампаниях → пилот годится для теста органики на своих каналах и проверки правил площадок.
- Время генерации: минуты (облако считает само), человек не участвует.

**Вариант 2 — «прод без вотермарок» (после валидации пилота):**
- TTS: SpeechKit v3 (0.7₽/клип) или Silero → аватар: **D-ID Plus ~$16/мес (~1280₽)** ≈ 30–60 клипов/мес без вотермарки, либо Vidnoz Starter $14.99 → монтаж локально.
- Себестоимость клипа 30 сек: **≈ 20–45₽** (подписка облака + TTS + электричество), при 60 клипах/мес ≈ 1300–2700₽/мес.
- Опция 3 (не рекомендована на старте): аренда GPU (RunPod/Vast.ai) + MuseTalk/EchoMimic — цены аренды `null` (не проверялось, оценить отдельно при решении).

Оба варианта встраиваются в конвейер autoclip + video-director/video-editor/qa без изменений ролей (шаг «аватар» добавляется между TTS и монтажом).

## 5. Экономика и пилот

**Стоимость 30–60 сек аватар-ролика (таблица):**
| Путь | ₽/ролик 30с | Пропускная способность | Комментарий |
|---|---|---|---|
| Локально CPU (TTS+монтаж) | ~0 (электричество) | ограничена CPU | **аватар-шаг на CPU нереален** (раздел 1a) — полный локальный путь NO-GO |
| Облако free (Vidnoz 3 мин/день) | 0₽ | ~6 клипов/день, вотермарка 720p | для пилота/теста правил |
| Облако прод (D-ID Plus ~$16/мес) | ≈20–45₽ (подписка+TTS) | 30–60 клипов/мес | без вотермарки |
| Живой UGC-креатор (фриланс) | 500–3000₽/ролик | по найму | в 15–100 раз дороже; доверие выше |
| Безликий клип (текущий конвейер) | ~0₽ | высокий | 0₽, но нет «лица» → ниже доверие/удержание и закрыты кампании «ты в кадре» |

**Где аватар выгоднее:** когда нужен формат «ведущий в кадре» (обзоры, tips, «говорящая голова») с регулярностью ≥1 клип/день и бюджетом до 50₽/ролик; при ценах живого креатора от 500₽ и потребности 60 роликов/мес разница — 30 000–180 000₽/мес vs ~1 300–2 700₽/мес.

**Пилот-план (после утверждения v2, решение company):**
1. Ниша: 1 ниша из согласованных в SPEC A (согласование — на company).
2. Персонаж: 1 фиксированный синтетический образ (референс-фото/видео с чистыми правами, легенда, имя) + фиксированный голос (Silero ru_ MIT / SpeechKit голос).
3. 5 тестовых роликов по 30–45 сек в течение 5–7 дней, стек варианта 1 (0₽).
4. Метрики: (а) модерация — принят ли ролик хотя бы в 1 Klipni-кампанию с разрешённой синтетикой; (б) органика — retention/просмотры на своих каналах (VK/Telegram/YouTube с маркировкой) vs медиана безликих клипов; (в) санкции площадок (лейблы/ограничения).
5. **Kill-критерий:** 0 из 5 роликов проходят модерацию кампаний ИЛИ медианный retention аватара <50% от безликого клипа после 5 роликов → трек закрывается, аватар остаётся опцией только для собственных каналов; повторная попытка — только при новом значимом факторе (дешёвый GPU, смена правил Klipni).
