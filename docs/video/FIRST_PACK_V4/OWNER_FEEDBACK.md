# Owner feedback — Wardogs V4 remaster

Date: 2026-09-21
Status: binding acceptance criteria

## Corrections

1. All full dialogue subtitles must be in the **lower third**, centered, and inside the platform safe zone. 
2. Current V3 drafts are rejected: they are simple cuts, not concept-driven edits.
3. Each clip must be understandable without the source:
   - explicit question/problem in 0–2 seconds;
   - context/setup;
   - 2–4 ordered explanatory beats;
   - visual proof/callouts tied to gameplay;
   - conclusion/payoff and concise CTA.
4. Target duration: **35–55 seconds** when the concept needs explanation. Do not stretch with filler; short is acceptable only if the story is complete.
5. Add useful editorial layers: zoom/punch-in, freeze-frame, arrows/callout labels, progress/step indicator, info cards, clean transitions, restrained sound accents.
6. No decoration without information. Every visual layer must explain, orient, emphasize, or improve pacing.
7. Study existing ready-made vertical gaming/explainer templates and layouts on the public web. Reuse only pattern-level ideas; do not copy proprietary assets.
8. Create a reusable fleet template pack, not one-off filters.

## Required reusable templates

- `gaming-explainer`: Hook → context → 3-step explanation → payoff → CTA.
- `gaming-moment-breakdown`: cold-open payoff → rewind → annotated action → lesson → payoff.
- Bottom-subtitle system with 1–2 lines, per-phrase timing, highlighted keyword, and Shorts/TikTok safe zones.
- Annotation layer: arrow, target ring, numbered callout, stat/info card, chapter/progress pill.
- Transition set: hard cut, 4–6 frame dip, 105–112% punch-in, 0.3–0.5 s freeze-frame. No flashy transitions by default.

## Hard acceptance

- 1080×1920, H.264 High/yuv420p, source FPS or 30, AAC 48 kHz.
- Dialogue subtitles entirely below the visual center, baseline above the 200 px bottom safe zone; no subtitles in the upper half.
- Captions proofread; one phrase per card; ≤42 chars/line, max two lines.
- Visual change or information beat every 2–4 seconds in first 10 seconds.
- Each clip has a written concept map and shot list.
- Final loudness −14±0.5 LUFS-I, true peak ≤−1 dBTP.
- Independent audiovisual QA with timecodes and exact SHA-256.
- No publication before owner approval.
