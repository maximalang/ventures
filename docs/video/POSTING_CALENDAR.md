## 4. Механика конвейера и буфер

### 4.1 Буферные пороги (минимум готовых к публикации единиц, QA-passed)

| Канал | Минимальный буфер | Почему |
|---|---|---|
| YouTube Shorts Wardogs | 3 клипа | по MONETIZATION_PLAN пакет 3–5 клипов; не публиковать «в ноль» |
| Telegram (каждый канал) | 5 постов (5 дней) | неделя без срывов при остановке производства |
| Pinterest (каждый аккаунт) | 7 пинов (7 дней) | пины дешёвые в производстве, запас недели |

Правило: если буфер канала < порога → приоритет производства этого канала над расширением на новые. Никаких публикаций «день в день» после недели 1.

### 4.2 Ритм производства (autoclip + director/editor)

Исходники: 1 длинный ролик/стрим Wardogs → 5–10 клипов-кандидатов; Facts/Psychology — текстово-визуальные форматы (дешевле).

Еженедельный цикл:
- Пн: director разбирает 1 исходник → shot-list 5–10 моментов (ручной выбор смысловых моментов, правило QUALITY_STANDARD).
- Вт: autoclip генерит черновики + субтитры; editor ручная вычитка (мат, имена, числа, контекст).
- Ср: QA-гейт по чек-листу (preflight=PASS + hash-bound gate:qa=pass); готовые клипы в буфер.
- Чт–Вс: производство TG-постов (текст+картинка) и пинов (Facts/Psychology) на следующую неделю.
- Вс: планёрка, разбор метрик прошлой недели, решение о правках.

Трудоёмкость (оценка, LOW — без прямого замера, требует калибровки на Д0–7):
- 1 Wardogs-клип полного цикла: 30–60 мин человеческого слоя (director выбор + editor вычитка + QA).
- 1 TG-пост: 10–15 мин.
- 1 пин: 5–10 мин.

### 4.3 Роли

| Роль | Что делает |
|---|---|
| autoclip | черновой монтаж, субтитры, нарезка по таймкодам |
| director | выбор смысловых моментов, проверка контекста, честный хук |
| editor | вычитка субтитров/мата/имён, финальный рендер clean master 1080×1920 |
| QA (независимый) | gate:qa=pass привязан к SHA-256 публикуемого файла |
| publisher | нативная загрузка из clean master, фиксация URL/timestamp/hash |

Klipni-правило «не чисто ИИ»: минимум 2 записанных редакторских решения на клип, provenance source hash → таймкоды → render hash.

## 5. Метрики стабильности (еженедельный срез)

Трекер — простая таблица (CSV/markdown) в docs/video/tracking/WEEK_*.md; обновляется раз в неделю.

### 5.1 Метрики процесса (streak)
- publications_planned vs publications_done по каждому каналу (цель 100%).
- buffer_level на конец недели vs порог (из §4.1).
- posting_window_adherence: доля публикаций в целевом окне (цель ≥90%).
- qa_failures: количество клипов, не прошедших QA (индикатор качества входа).

### 5.2 Метрики результата по каналам

| Канал | Ключевые метрики |
|---|---|
| YouTube Shorts | views, VVSA (цель ≥70%), first-3s completion (≥60%), completion, подписчики, подтверждённые Klipni-просмотры, rejection reason |
| Telegram | подписчики, ERR (цель ≥15%), пересылки/пост, реакции/пост |
| Pinterest | impressions, saves, outbound clicks (если есть), подписчики |
| TikTok (после GO) | views, completion, shares, подписчики |
| VK (после GO) | views, completion, переходы в профиль, подписчики |

### 5.3 Stop-rules (из MONETIZATION_PLAN, применять без изменений)
- Два клипа подряд VVSA<50% или first-3s<60% → стоп серии, переписать frame 1/первую фразу.
- Любой compliance/reused/rights reject → hold следующего пакета.
- 0 принятых из первых 3 submissions → STOP, разбор с Klipni.
- 100% QA/package coverage — один плохой клип не компенсируется средним пакета.

## 8. Что НЕ входит (явные границы)

- Публикации любого контента до owner GO.
- Платное продвижение (посевы, Telegram Ads, VK Ads) — бюджет 0 ₽, отдельное решение владельца.
- Накрутка подписчиков/реакций — запрещена compliance и бесполезна (алгоритмы фильтруют, ERR падает).
- Кросс-постинг одного ролика без адаптации между площадками (SPEC_I запрет; адаптационная матрица — в PLATFORM_ADAPTATION.md, который ещё не создан — пробел).
