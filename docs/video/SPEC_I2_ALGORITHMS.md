## Задача 1 — алгоритмы (детально, по каждой площадке волны 1)
Площадки: VK Клипы/Видео, YouTube Shorts, TikTok, Instagram Reels, Telegram, Pinterest.
По каждой (источник+дата+confidence; цифры без источника = null):
1. Что ранжирует алгоритм в 2025–2026 (удержание первых секунд, completion, rewatch/loop, shares, comments, session time — с весами где известны).
2. Механика посева: test-аудитория, first-hour окно, условия масштабирования, повторная дистрибуция (вторичные волны).
3. За что режет охваты: неоригинал, вотермарки чужих площадок, AI-лица, частота постов, удаление/перезалив.
4. Холодный старт нового аккаунта: как набрать первые 1k подписчиков на этой площадке (что работает именно для новых каналов).
5. Оптимальная частота и время постинга для RU-аудитории (данные, не фольклор).
6. Табу и бан-риски.

## Задача 2 — стабильный постинг-контур
1. Контент-календарь пилота: частота на каждый канал/бренд (исход из данных задачи 1), минимум 2 недели вперёд.
2. Механика конвейера: буфер готовых роликов ≥ N дней на канал (не публиковать «в ноль»), кто/что генерит и в каком ритме (autoclip + director/editor).
3. Метрики стабильности: публикации без пропусков (streak), окно постинга соблюдено, буфер не ниже порога.
4. Дашборд/отчётность: еженедельный срез по каналам (охват, удержание, подписчики) → вход для решения «масштабировать/править».
