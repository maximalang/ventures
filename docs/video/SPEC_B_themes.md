# SPEC B — Тематики/направления: что «стреляет» на каждой площадке

Общий контекст и метод: `RESEARCH_BRIEF_v2.md` (прочитать ПЕРВЫМ). execute_code запрещён.

## Задача
Определить КОНКРЕТНЫЕ тематики (ниши/направления контента), которые показывают лучшие результаты на каждой приоритетной площадке в 2026, и сопоставить их с производственными возможностями флота (клиппинг чужих длинных видео, AI-генерация, MoneyPrinterTurbo, автоматизированный конвейер без лица/голоса автора).

## Что исследовать
1. **По каждой площадке** (YouTube Shorts, TikTok, IG/FB Reels, VK Клипы, Дзен, Telegram-видео, X) — какие ниши дают максимум просмотров/CPM/удержания в 2025–2026. Искать: отчёты платформ, разборы агентств, данные creator-economy изданий (vidIQ, Tubefilter, Socialinsider, Rival IQ, Buffer, Later, внутренние RU-источники: vc.ru, Хабр, TJ-наследники), CPM по нишам.
2. **Кросс-площадочные универсальные ниши** коротких видео: gaming clips, AI-tools/tech, finance/money, motivation, facts/history, satisfying/ASMR, pets, DIY/crafts, true crime, sports, мемы-нарезки стримов, «истории из жизни» (Reddit/TTS), обучающие микро-уроки, товарные обзоры (для e-com), музыкальные нарезки. По каждой: ёмкость, конкуренция, монетизируемость из РФ, совместимость с автоматизацией.
3. **Совместимость с производством флота** — критично. Для каждой ниши оценить:
   - Можно ли производить конвейером (autoclip/MoneyPrinterTurbo) без лица и голоса человека?
   - Где требуется human touch (UGC, лицо в кадре) — это отдельная категория с другими затратами;
   - Риск «inauthentic/AI-slop» фильтров платформы в этой нише;
   - Где есть лицензионная чистота (чужие стримы → только через клиппинг-кампании с разрешением; стоковый футаж; собственная генерация).
4. **Ниши под Klipni-кампании** (наша текущая точка входа): gaming (GTA5RP, WarDogs) — что внутри gaming стреляет (фейлы, скилл-моменты, реакции, разборы), какие под-ниши дают больше просмотров на VK/YT.
5. **Тренд-радар**: какие тематики растут в 2026 (AI-видео, «brainrot»-контент, silent vlogs, ASMR-ремесла, локализация западных форматов на RU и наоборот — RU→ENG каналы).

## Deliverable
`THEMES_MATRIX.md`: матрица «площадка × тематика» (что стреляет где, с цифрами просмотров/CPM где доступны) + рейтинг 10 лучших тематик для автоматизированного конвейера флота (критерии: монетизируемость из РФ, автоматизируемость, лицензионная чистота, конкуренция) + по каждой рекомендуемая площадка-микс. Источники с датами.
