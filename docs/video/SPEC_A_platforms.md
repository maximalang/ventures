## Для каждой площадки заполнить
| Поле | Что нужно |
|---|---|
| Статус из РФ 2026 | работает / ограничен / заблокирован; как технически работать (VPN, зарубежный номер, покупной аккаунт) |
| Контингент | возраст/гео/интересы аудитории, язык, что смотрят |
| Монетизация прямая | есть/нет для РФ-резидента; пороги; ставки (CPM/за просмотр/бонусы) |
| Монетизация косвенная | партнёрки, донаты, брендовые интеграции, клиппинг-платформы поверх |
| Вывод денег | способы из РФ: карта РФ, крипта (USDT/TON), посредники с комиссией (какие сервисы, %, легальность для самозанятого), PayPal-обменники |
| Отношение к AI-контенту | принимают/банят; правила уникальности, автопостинга |
| Риски | ToS/бан/юр-риск РФ (для Meta отдельно) |
| Вердикт | PRIORITIZE / VIABLE / MARGINAL / NO-GO + confidence |
