## Архитектура завода (проектируется картами ниже)
Принципы:
1. **Мастер-контент → адаптации**: один мастер-ролик/статья → N площадочных версий (Δ7 V4). Не N отдельных производств.
2. **Канал-сетка**: множество каналов по нишам THEMES_MATRIX (не один канал обо всём). Каждая ниша = свой бренд/handle/voice.
3. **Стабильность = конвейер, не геройство**: недельный batch-цикл (plan→script→produce→QA→schedule), SLA по частоте на канал, буфер готовых единиц ≥2 недель.
4. **Качество-гейты на каждом этапе**: hook-гейт (≥72 yt / ≥60 reels), QA creative+technical, голос канала (voice.md), табу площадок.
5. **Обучающий контур**: аналитика → retention/audit → следующий batch (A/B по хукам/темам/площадкам).
6. **Юр-чистота**: erid/рекламные ограничения по каждой площадке (IG — запрет рекламы; X/Snapchat NO-GO; TikTok/IG MARGINAL-эскалации) — фиксируются в паспорт канала.
7. **0₽ вход**: регистрация через Google/email флота без телефона; закупка аккаунтов/номеров отменена (Δ2 V4). Платное — только по trigger'ам и ГО владельца.

## Карты стрима
- **F-ARCH** (product): Архитектура контент-завода — канал-сетка (какие ниши × какие площадки × сколько каналов), частотный SLA, batch-конвейер, роли/gates, буферная политика. Выход: CONTENT_FACTORY.md.
- **F-RANK** (research): Ранжирование площадок под каждую нишу THEMES_MATRIX — пересечение PLATFORMS_MATRIX × монетизация × усилия × юр-риски; delta к существующим докам (не пересказ). Выход: PLATFORM_RANKING.md.
- **F-MON** (finance): Юнит-экономика завода — cost/видео по типам (клиппинг vs оригинал vs аватар), break-even по площадкам, прогноз дохода 1/3/6 мес по сценариям (консервативный/базовый/агрессивный), kill-критерии. Выход: FACTORY_ECONOMICS.md. Все числа с источниками; неизвестное = null.
- **F-OPS** (operations): Операционный план регистрации N каналов — порядок, входы (Google без телефона), сессии/профили браузеров, антифрод-ограничения площадок (сколько регистраций/день безопасно), реестр аккаунтов. Выход: CHANNELS_OPS_PLAN.md + шаблон паспорта канала.
- **F-PILOT** (company, после F-ARCH/F-RANK/F-MON/F-OPS): сводный пакет владельцу — план завода + пилотная волна (какие каналы стартуют первыми, контент-план 2 недель, примеры) → ГО владельца → старт.
