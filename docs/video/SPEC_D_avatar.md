# SPEC D — Виртуальный ведущий (аватар-персонаж): полная автоматизация производства «вместо человека в кадре»

Общий контекст и метод: `RESEARCH_BRIEF_v2.md` (прочитать ПЕРВЫМ). execute_code запрещён.

## Директива владельца (16.09, уточнение)
Аватар — НЕ просто «лицо поверх клипа», а **полноценная замена человека в кадре**: виртуальный ведущий/персонаж, который ведёт ролик от начала до конца, чтобы всё производство было end-to-end автоматическим — сценарий → голос → аватар в кадре → монтаж → субтитры → публикация, **без участия человека вообще**. Это открывает те форматы и кампании, где требуется «ты в кадре» (UGC, обзоры, «говорящая голова», reaction-форматы), и снимает зависимость от живого креатора.

## Этическая/юридическая рамка (первым разделом в отчёте)
1. **Персонаж полностью синтетический** — несуществующий человек, сгенерированный с нуля. Запрещено: лица реальных людей (владельца, знаменитостей, стоковых моделей без письменной лицензии), клонирование чужого лица/голоса. Это не «обман платформы» в смысле deepfake реального лица — это виртуальный блогер, практика существующая и легальная.
2. **Обязательная маркировка AI-контента** по правилам каждой площадки (YouTube altered/synthetic disclosure, TikTok AI-label, Meta AI-label, VK правила о синтетике/дипфейках). Research фиксирует точные требования и как маркировать, чтобы не получить бан/демонетизацию.
3. **Голос** — синтетический TTS (или клон голоса владельца ТОЛЬКО с его письменного согласия — отдельный touchpoint). Чужие голоса запрещены.
4. **Честность перед брендами:** если UGC-кампания требует «живого человека», аватар может не пройти модерацию и/или быть расценен как нарушение брифа. Research обязан выяснить приёмку (см. блок 4) и НЕ предлагать отправлять аватар туда, где это нарушение правил — вместо этого найти кампании/площадки, где синтетика разрешена.
5. Никаких инструкций по обходу верификации личности/платёжных identity. Обход = только контентные требования «человек в кадре» через легальную синтетику с маркировкой.

## Блок 1. Инструменты генерации аватара-ведущего (2026)
**Ключевое ограничение нашего железа:** CPU-only ноут (GPU нет; Timeweb VDS 1GB RAM; GPU на Timeweb только по заявке в продажи). Поэтому приоритет — что работает на CPU или в облаке бесплатно/дёшево.

### 1a. Локальные OSS (проверить: RU-липсинк, качество, CPU-время на 30 сек, лицензия для коммерции)
- Говорящая голова из одного фото: SadTalker, LivePortrait, EchoMimic v2/v3, Hallo 2/3, Sonic, MuseTalk, DreamTalk, AniPortrait, LatentSync, JoyHallo.
- Полный персонаж/тело + жесты (не только лицо): Anima, UniAnimate, Champ, MagicAnimate, MimicMotion, DreamActor (ByteDance) — что реально запускается локально vs требует GPU.
- Consistency персонажа между роликами: фиксированный seed/референс-фото/LoRA на своё сгенерированное лицо (InstantID, IP-Adapter FaceID, PhotoMaker, PuLID) — как добиться одного и того же лица в каждом клипе.
- Для каждого: минимальные требования (VRAM/RAM), время генерации 30-сек вертикального видео, качество липсинка на русской речи, лицензия (MIT/Apache = можно; non-commercial = нельзя без override владельца).

### 1b. Облачные API (цена за минуту, доступность оплаты из РФ, RU-липсинк, бесплатные кредиты)
HeyGen, D-ID, Synthesia, Argil, Hedra, Kreado AI, Vidnoz, Yepic, Colossyan, RenderNet, Pollo AI, а также российские (Sber SaluteSpeech/аватары Kandinsky, Yandex SpeechKit, VK-инструменты если есть). Отдельно: агрегаторы с оплатой картой РФ и через крипту (например Pollo/через посредников) — как платить из РФ в 2026.

### 1b+. Канал покупки доступов (вводная владельца 16.09 — ОБЯЗАТЕЛЬНО исследовать)
Владелец может дёшево покупать доступы к платным нейросетям на **FunPay** (много предложений под все основные нейросети: дешёвые и качественные) и других площадках. Для каждого рекомендованного облачного сервиса проверить:
1. Наличие и типичные цены лотов на FunPay (публичные страницы читаются без аккаунта): аккаунты, подписки, shared-доступы, «под ключ» — к HeyGen, D-ID, Hedra, Kreado, Kling, Runway, Veo, Pika, Midjourney и т.д.
2. Альтернативные площадки: Plati.market, GGSEL, Digiseller — наличие тех же категорий.
3. Риски: общие/shared аккаунты (лимиты, конфликт), угнанные аккаунты (бан), отсутствие гарантии, блокировка платежей, ToS-риски самого сервиса (resale/shared accounts = ban). Уровень риска по каждому типу лота.
4. Экономика: «₽/ролик через купленный доступ» vs официальная подписка vs локальный CPU-конвейер — в таблицу блока 5.

### 1c. Голос (TTS) для персонажа
Silero TTS (локальный, бесплатный, RU), Piper, Coqui/XTTS-v2 (мультиязычный, клонирование голоса), GPT-SoVITS (клон с согласия), Yandex SpeechKit (₽), ElevenLabs (доступность из РФ), Fish Audio, Kokoro. Критерии: качество RU, скорость, стоимость минуты, возможность зафиксировать ОДИН уникальный голос персонажа (seed/voice-id).

### 1d. Рекомендуемый стек
Дать 2 варианта: (1) полностью локальный CPU-конвейер (максимально бесплатный, медленный) с временем генерации 30-сек клипа; (2) гибридный (локальный монтаж + облачный аватар по API) со стоимостью за ролик. Оба встроить в существующий конвейер autoclip + video-director/video-editor.

## Блок 3. End-to-end автоматизация (главное требование владельца)
Спроектировать полный конвейер без человека:
1. Выбор темы/кампании (research-агент) →
2. Сценарий + хук (video-director) →
3. TTS-озвучка фиксированным голосом персонажа →
4. Генерация аватар-видео (локально/API) →
5. Монтаж: B-roll/клипы поверх, субтитры, музыка, плашки бренда, вертикаль 1080×1920 (video-editor + autoclip) →
6. QA-гейт (qa-профиль, независимый) →
7. Публикация на площадки + отправка в кампанию (operations) →
8. Трекинг просмотров/выплат.

Для каждого шага: какой инструмент, время, стоимость, где ещё нужен человек (если нужен — назвать и предложить как автоматизировать), какие есть готовые OSS-проекты под это (MoneyPrinterTurbo уже установлен — оценить как базу: умеет ли аватар/лицо, или только футаж+TTS; найти аналоги с аватаром: MoneyPrinter, ShortGPT, NarratoAI, Cloney, AI-Youtube-Shorts-Generator и др. — лицензии и пригодность).
