# SPEC M — Другие логичные и качественные пути по видео (за пределами клиппинга)

Контекст: `RESEARCH_BRIEF_v2.md` + `VIDEO_STRATEGY_V3.md` (КАНОН) + MONETIZATION_CATALOG.md (F, 75 механизмов). execute_code запрещён.

## Директива владельца (17.09)
«Плюс другие способы и пути по видео, которые логичны и качественны».

## Смысл задачи
Каталог F уже дал 75 механизмов, но он ориентирован на «заработок на просмотрах». Нужен **стратегический слой**: какие ещё видео-направления логично вытекают из того, что у нас УЖЕ есть (готовый производственный конвейер autoclip+director/editor/qa+MPT+аватар, headless-браузеры, MTProto-сессия TG, опыт в SEO/HR-продуктах, freelance-отдел, Timeweb VDS), и дают качественную, устойчивую (не зависящую от виральности) выручку.

## Критерии отбора «логично и качественно»
1. Использует существующий конвейер/навыки (низкий маржинальный cost of entry).
2. Не зависит исключительно от просмотров/алгоритма (устойчивость).
3. Белый или умеренно-серый юр-класс (НПД-совместимо предпочтительно).
4. Качество результата проверяемо (не «штамповка мусора»).
5. Масштабируется без пропорционального роста ручного труда.
6. Совместимо с политикой: никакого mass outreach, никаких чужих персональных данных, никакого фрода.

## Направления для обязательной проверки (каждое — вердикт + экономика + evidence)
1. **Видео-SEO / видео для сайтов продуктов флота**: видео-объяснения для калькуляторов мвп-пени-сайта, демо Recruiter Radar, программное видео-SEO (massive scale: сотни страниц с уникальными видео — есть ли RU-практика, как монетизируется: трафик→лиды→продукты, рекламные вставки). Логично: у нас SEO-компетенция уже есть.
2. **Видео-локализация/дубляж как услуга**: RU→ENG и ENG→RU перевод+озвучка+липсинк существующих видео (услуга на фрилансе, спрос от блогеров/компаний). Есть OSS-стек (whisper+TTS+липсинк). Ставки рынка.
3. **Автоматизация видеопродакшена для других (B2B-SaaS/агентская модель)**: продавать не ролики, а настройку конвейера (white-label, консалтинг, «видео-отдел под ключ» для агентства/блогера). Ставки, рынок RU.
4. **Образовательные видео-продукты**: микрокурсы в вертикальном формате (своя ниша: AI-инструменты, freelance-навыки), продажа через Boosty/Tribute/собственный сайт (Робокасса у нас уже есть!). Экономика, спрос, анти-паттерны (инфоцыганство — как не стать им, качество).
5. **Видео-контент для e-commerce**: товарные ролики для продавцов WB/Ozon (огромный RU-рынок), карточки с видео, обзоры товаров — ставки, как искать клиентов (не mass outreach), автоматизируемость.
6. **Лицензирование/стоки собственного футаж-контента**: генерируем качественный stock-футаж (AI-видео) и продаём на стоках — какие принимают РФ, ставки, эксклюзивность.
7. **Видео-агентство полного цикла для локального бизнеса** (Рязань/РФ): рекламные ролики, reels для кафе/услуг — рынок, чек, как продавать без mass outreach (inbound-витрина, партнёрства, Klipni-UGC кампании как портфолио).
8. **Синтетические ведущие для медиа/компаний**: новостные дайджесты, корпоративные коммуникации, HR-онбординг видео — есть ли RU-спрос и бюджеты.
9. **Видео-подкасты/интервью с аватаром**: переработка текстового контента (нашего или чужого с правами) в видео-подкаст-формат — модели монетизации.
10. **Faceless YouTube-каналы на ENG** (без зарубежного платёжного контура — проверить: как монетизировать ENG-канал из РФ БЕЗ AdSense и БЕЗ EasyStart (решение владельца: зарубежный контур НЕ берём): через Klipni-кампании с ENG-аудиторией? через affiliate с выводом в РФ? через продажу канала как актива (Telderi)?).
11. **Видео для Telegram-экосистемы**: платные TG-каналы с видео-контентом, Stars-механики, видео-боты (услуги через бота с оплатой Stars — у нас уже есть опыт TG-интеграций). Экономика.
12. **Найти минимум 3 направления самостоятельно** (чего нет в этом списке): например, видео-арбитраж трафика на белые офферы, UGC-агентство для брендов с аватар-моделями, «видео-утилиты» (сервисы конвертации/сжатия/субтитров как SaaS — у нас SEO-сайт опыт), спортивные/ставки-дайджесты (с пометкой юр-риска), детские/образовательные каналы, ASMR/sleep-контент, религия/мотивация и т.д.

## По каждому направлению дать
- Суть одной фразой.
- Почему логично для нас (какой существующий актив используем).
- Рынок и спрос (объём, ставки, конкуренты — с evidence, не на глаз).
- Экономика: доход/мес в 3 сценариях, себестоимость, ₽/час при автоматизации, точка безубыточности.
- Юр-класс (белый/серый/красный) и что именно рискованно.
- Автоматизируемость нашим конвейером 0–5 и какая новая роль/инструмент нужны (триггер создания спецагента по ORG_MODEL.md).
- Вердикт: PRIORITIZE / VIABLE / PARK / NO-GO с обоснованием.
- Пробелы null.
