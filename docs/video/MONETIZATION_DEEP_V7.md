### 1А. Углубление по директиве владельца (MON-V7-A, срез 24.09.2026)

**Гео-рамка (фундамент всех путей TikTok):** регион аккаунта определяется не полем «страна» в профиле, а связкой IP + SIM/eSIM + поведенческая история + страна платёжных реквизитов (multilogin 26.02.2026 [T6], M-H). Смена региона «на бумаге» без смены всей связки = риск перманентного бана без восстановления при первой верификации выплат (pampadu [T7], M — aff-вендор, но фактология гео сходится с [T6]). Просмотры RU-аудитории не оплачиваются даже на «западном» аккаунте (реклама в РФ отключена) [T7]. Вывод: любой «обход гео» = ToS-риск HIGH + серые деньги → по правилу спеки «серая зона = сразу минус» все нативные пути TikTok = null, а не «сложно но можно».

**LIVE Gifts — экономика (для калибровки, НЕ для плана):** зритель покупает Coins (~$0.010–0.011/монета, пакеты $0.99/65 … $99.99/6607 [T8], M) → Gift → автор получает Diamonds (курс ~2 coins = 1 diamond) → вывод $0.005/diamond. Доля автора: 4 независимых источника дают ~50% от потраченного зрителем (biztoolkit 21.05.2026 [T9], influencerfee 09.2026 [T10], ytmoneycalculator [T11], revenuelab [T12], все M); streamer.guide (04.09.2026 [T13], M) при полном учёте комиссии магазина приложений оценивает реальную долю ближе к 25%. Диапазон 25–50%, conf M. Пороги: 18+, 1000 подп. для LIVE. Бенчмарк: микро-автор 10–100k подп. $40–250 за LIVE-сессию [T10, M]. Для РФ: LIVE приостановлен с 03.2022 (dtf/hi-tech.mail.ru [T14], H) + выплаты требуют банк страны аккаунта → null. **РФ-аналог этой механики = TG Stars (§4) и Boosty-донаты, а не TikTok.**

**Bio-воронка — обновлённые бенчмарки 2026 (важно: ссылка кликабельна только у business-аккаунтов [T7]):** bio CTR 1–4% от визитов профиля (lenkli 15.12.2025 [T19], M); до 3–8% у сильных аккаунтов, топ ≥10% (sozee 08.09.2026 [T20], L/M — вендор, но диапазоны сходятся); медиана click→sale из TikTok-органики ~1.2% (датасет 50k+ bio-страниц tapmy.store 2026 [T21], M). **Продажа цифровых продуктов (пресеты/LUT/шаблоны CapCut) — уточнение пути 3 с цифрами:**

- Флот-синергия: шаблоны CapCut/LUT/пресеты = продукт нулевой маржинальной себестоимости из выхлопа конвейера (монтажные пресеты завода → упаковка). Ниша «как монтировать» = education, click-to-sale 3.1% vs 0.9% lifestyle ([S14] базы).
