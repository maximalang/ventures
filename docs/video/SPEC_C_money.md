# SPEC C — Деньги: партнёрки за просмотры + сервисы вывода с комиссией

Общий контекст и метод: `RESEARCH_BRIEF_v2.md` (прочитать ПЕРВЫМ). execute_code запрещён.

## Задача
Построить полную карту монетизации видео из РФ в 2026: кто платит за просмотры напрямую (включая зарубежные программы, доступные через VPN/посредников), и через какие сервисы можно выводить деньги с комиссией (включая крипту и обменники), с оценкой легальности для самозанятого РФ.

## Блоки исследования
1. **Партнёрки/программы, платящие за просмотры, доступные из РФ (прямо или через обход):**
   - RU: VK Видео (ставки, как подключиться, самозанятость), ОК, Дзен (если что-то появилось для видео), Telegram (Stars/TON, реклама), Yappy/Likee если платят.
   - Клиппинг-платформы: Klipni (уже работаем), все остальные найденные — DareBay, cliper.work, Prime Oracles, Vyro, Whop, Clipyour (и любые новые 2026): условия, валюта, гео-блоки, минимум вывода.
   - Зарубежные creator-программы: YouTube (через посредников-агентств/MCN, принимающих РФ-каналы? реальные кейсы 2025–2026), Facebook Performance Bonus, TikTok Creator Rewards (доступность через зарубежную SIM/аккаунт — факты и риски), Snapchat Spotlight, X payouts.
   - MCN-сети и «агентства-посредники», которые берут RF-креаторов и выводят деньги (найти конкретные, проверить живость и репутацию, комиссии).
2. **Сервисы вывода с комиссией (посредники):**
   - Крипто-мост: USDT/TON — какие биржи/обменники работают с РФ-картами в 2026 (P2P), комиссии, лимиты, KYC-риски, легальность для самозанятого (декларирование дохода в НПД с крипты).
   - Платёжные посредники/«выплаты зарубежным креаторам»: сервисы типа Debitum, EasyStart, Solar Staff, Payoneer-альтернативы — кто обслуживает РФ в 2026, комиссии, что нужно для регистрации (KYC-порог!).
   - Обменники PayPal/зарубежных балансов → карта РФ: типичная комиссия (5–15%?), риски (скам, AML-блокировки карт), как выбирать.
   - Donational-мосты (Boosty как аналог Patreon — для своих каналов).
3. **Юридический контур самозанятого (НПД):**
   - Можно ли декларировать доход от зарубежных платформ/крипты в «Мой налог»? Как (валюта→₽ на дату получения)?
   - Ограничения НПД (2.4 млн ₽/год лимит, запрещённые виды) — применимость к видео-деятельности.
   - Риски: 115-ФЗ блокировки при регулярных крипто-поступлениях, что рекомендует практика 2026.
   - Маркировка рекламы (ERID/ОРД): кто обязан — креатор или платформа (Klipni заявляет договор на себе; проверить для зарубежных площадок и для своих каналов с интеграциями; штрафы).
4. **Экономика каждого маршрута:** для топ-5 маршрутов вывода посчитать потери (комиссия платформы + комиссия посредника + НПД 4–6% + курсовые) и «чистыми на 100к₽ gross».

## Deliverable
`MONEY_ROUTES.md`: таблица маршрутов (источник выплаты → посредник → куда приходит → комиссии → легальность для НПД → риск → вердикт), раздел по каждой партнёрке с условиями, юр-раздел с источниками, расчёт чистой экономики топ-5 маршрутов. Всё с URL и датами; где данных нет — `null` + «что проверить экспериментом».
