### 2.1 Transformative-стандарт (что считается substantive editing)

Опорный критерий — YT reused-content политика (H, см. §1.1): «content downloaded or copied from another online source without any substantive modifications» не монетизируется. «Substantive» в политике не расшифровано количественно → **граница трансформации = null**, не выдуманная цифра.

Практическое правило для линии (рабочая гипотеза, M, не из первички):
- Транс­формация = собственная нарезка + собственная озвучка/субтитры + собственный монтаж, причём исходный фрагмент не доминирует в кадре (точный порог не установлен; проверять по каждому кейсу).
