# F-PILOT v2 — пакет контент-завода (правка по замечаниям владельца 23.09)

v2 vs v1: ① Wardogs — не ядро, а одна из трёх ног (вес смещён на evergreen); ② двухнедельный shadow-test ОТМЕНЁН — короткий буфер и сразу живые публикации; ③ TikTok — в волну 1 (ГО владельца 22.09 в силе, регистрация через Google — задача флота); ④ монетизация — микс нескольких потоков, не 2.

## 1. Wardogs — почему был акцент и что меняется

Причина в v1 (reuse-first): уже есть живой YT-канал, привязка к Klipni, подтверждённые права и готовые паки (NG-01 QA PASS, v3/v4) — самые быстрые деньги с дня 1, поэтому P0.

Замечание владельца принято: RP-гейминг одной игры = узкий потолок и зависимость от одного источника. Правка:
- **Wardogs — одна из трёх ног, не ядро.** Роль — валидация Klipni + быстрый первый рубль, не основной объём.
- **Вес производства смещён на evergreen** (facts/history/science, psychology/stoicism/sleep): не устаревают, масштабируются TTS-конвейером, лучше ложатся в микс монетизации (VK-партнёрка, Boosty, донаты, CPA).
- Мастера/нед: **Wardogs 3** (было 5), **facts 4**, **psychology 4**. Evergreen = 8 из 11 мастеров.

## 2. Тест: 2 недели — отменено

Двухнедельный «теневой» прогон убран (замечание принято: качество единицы и так защищено гейтами G0–G4, а ритм быстрее виден на живых публикациях, не в вакууме).

- **Д0–Д3: короткий буфер** — один batch-цикл (11 MCU + ~35 пакетов), чтобы каналы стартовали не пустыми. Регистрации идут параллельно (не зависят от производства).
- **Д3+: публикации сразу** по SLA (VK/YT/TG/TikTok).
- Вместо pre-launch теста — **живые гейты Д7 и Д14**: first-pass QA ≥80%, 0 критических rights-дефектов, ритм ≥80% SLA. Провал = точечная починка узкого места, остальные каналы не останавливаем.
- Экономические kill-критерии (₽/час, медиана просмотров) — на Д30, без изменений.

Юр-граница (сохраняю): крипто-маршруты (Stars→TON, DareBay USDT) с 01.01.2025 = НДФЛ 13%, не НПД; TikTok/Meta/X creator-rewards из RF = HIGH ToS-риск. Чистое ядро = VK + Klipni + Boosty + Track B (все НПД).
