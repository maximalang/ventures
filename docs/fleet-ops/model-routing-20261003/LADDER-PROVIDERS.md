## Правила лестницы

1. Качество первым: список класса начинается с модели, подтверждённой для класса
   задач; дешёвая модель допустима в списке только там, где её качество для класса
   доказано (дух RouteLLM).
2. Провайдерное разнообразие: соседние элементы списка — разные провайдеры;
   максимум 2 модели одного провайдера в списке и не на первых двух местах —
   отказ одного провайдера не должен обнулять класс.
3. Временные рельсы (T2) не входят в списки; только чрезвычайный ручной пин
   отдельным решением.
4. Vision — только подтверждённые рельсы: qwen-vl-max (прямая), gpt-6-luna
   (aux-зрение); NEMOTRON/OPENROUTER-free на vision запрещены (канон).
5. Независимость QA: рельса review не должна совпадать с рельсой автора; при
   совпадении — шаг вправо (это уже инвариант роутера).
6. Деградация: весь список недоступен → дефолт профиля с пометкой degrade.
7. Пересмотр: еженедельно по KPI; kill-критерий модели в классе — QA-block rate
   выше цели класса 2 недели подряд; замена — одной правкой строки списка.
