# Project Charter — Venture Lab

## Problem
Портфель требует дисциплинированного механизма поиска и валидации одного следующего прибыльного полезного продукта без распыления ресурсов.

## Customer
Сегмент определяется отдельно для каждой гипотезы; запрещено начинать build без конкретного пользователя и evidence проблемы.

## Success metric
Один активный venture проходит evidence-based `GO/NO-GO`; после GO создаётся отдельный project board и проверяемый MVP/эксперимент.

## Scope
- In: поиск сигналов, shortlist ≤3, market/user evidence, pre-mortem, unit economics, channel test.
- Out: параллельное строительство нескольких продуктов, публичный launch без approval, выдуманные цифры.

## Current gate
Discovery — выбрать первую hypothesis card на `portfolio` board.
