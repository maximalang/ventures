# Company OS

Hermes-native контур для портфеля автономно развиваемых продуктов.

## Миссия

Находить подтверждённый спрос, создавать полезные продукты, доводить их до выручки и улучшать в безопасных пределах.

## Канон

1. **Kanban** — фактическое состояние работы, владельцы, зависимости, review и блокировки.
2. **PORTFOLIO.md** — реестр явно зарегистрированных проектов и один активный новый venture.
3. В каждом проекте: `CHARTER.md`, `STATE.md`, `decisions/`.
4. `OPERATING_SYSTEM.md` — общий цикл, convergence и handoff.
5. `APPROVALS.md` — граница автономности.

Hermes `ox-alpha` остаётся единственным интерфейсом пользователя. Профиль `company` ведёт portfolio board и эскалирует approval-запросы в свой Bot Chat; `ox-alpha` собирает решения пользователя и контролирует исполнение.

## Не копируем из Auto-Company

- отдельный WSL/systemd/30-секундный daemon;
- `danger-full-access` и безусловный YOLO-режим;
- один перезаписываемый глобальный `consensus.md`;
- созыв всех ролей на каждый цикл;
- бесконечную дискуссию, имитацию известных людей и неконтролируемую публикацию.

Используем нативные Hermes Profiles, Projects, Kanban, Cron/Routines, worktrees, skills и evidence-first review.
